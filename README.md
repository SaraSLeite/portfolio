# Portfólio — Sara Leite

Portfólio pessoal com identidade editorial em preto, vermelho intenso e branco, inspirado em design gráfico e interfaces digitais.

## Como executar

Este projeto usa HTML, CSS e JavaScript no diretório `public/`, servido por um servidor Express simples.

1. Instale o Node.js, caso ainda não esteja instalado.
2. No terminal, entre na pasta do projeto.
3. Execute `npm install`.
4. Execute `node server.js`.
5. Acesse o endereço local informado pelo servidor (por padrão, `http://localhost:3000`, dependendo da configuração do ambiente).

Também é possível abrir `public/index.html` diretamente no navegador, mas alguns recursos externos precisam de conexão com a internet.

## Personalização

- `public/index.html`: conteúdo e estrutura das seções.
- `public/site.css`: cores, layout, responsividade e animações.
- `public/scripts.js`: menu mobile, tema claro/escuro, leitura em voz alta e controles da linha do tempo.
- `public/img/`: imagens e identidade visual.

Os links dos cartões de projeto direcionam ao perfil GitHub, pois os endereços individuais dos repositórios não foram definidos no material recebido.
